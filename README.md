Ο ήρωας μέσα μου!

Serious Game για παιδιά με Οξεία Λεμφοβλαστική Λευχαιμία (ALL)

Το «Ο ήρωας μέσα μου!» είναι ένα Serious Game που αναπτύχθηκε στο πλαίσιο διπλωματικής εργασίας, με στόχο να συνδυάσει το παιχνίδι με έναν πιο φιλικό και διαδραστικό τρόπο συμπλήρωσης ερωτηματολογίου.

Το παιχνίδι ακολουθεί τη λογική ενός endless runner, με πρωταγωνίστρια την Amy. Κατά τη διάρκεια της διαδρομής, ο παίκτης αποφεύγει εμπόδια, συλλέγει αντικείμενα και συναντά διαφορετικούς ιούς, οι οποίοι συνδέονται με πέντε ερωτήσεις για τη σωματική και συναισθηματική κατάσταση του παιδιού.

Οι απαντήσεις καταγράφονται χωρίς βαθμολογία και μπορούν να προβληθούν συγκεντρωτικά ή μέσα από διαγράμματα προηγούμενων συνεδριών.

Τεχνολογίες και εργαλεία

- Unity 2022.3.9f1 : Ανάπτυξη παιχνιδιού
- C# : Προγραμματισμός
- Visual Studio : Επεξεργασία κώδικα
- Adobe Mixamo : Χαρακτήρας Amy και animations
- Unity Asset Store : 3D μοντέλα και γραφικά στοιχεία
- TextMeshPro : Κείμενα και στοιχεία διεπαφής
